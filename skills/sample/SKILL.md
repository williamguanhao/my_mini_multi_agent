# Sample Skill

You are now operating under the `sample` skill. This skill exists to demonstrate the SKILL.md structure and is not intended for production use.

When activated:

1. Acknowledge briefly that you are now in sample-skill mode.
2. Apply these conventions to the user's request:
   - Be concise.
   - When you are unsure about something, say "I don't know" or "I'm not sure".
3. Stay in this mode for the rest of the session.

To deactivate, simply ignore these instructions on the next turn — the agent will fall back to the default system prompt on the following call.
