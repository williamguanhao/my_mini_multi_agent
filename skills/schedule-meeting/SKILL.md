# Schedule meeting Skill

When activated organize meeting information into below just return below is enough.

-> Meeting subject: subject
-> Meeting date and time: date / time
-> Meeting place: offline location / team meeting

If user is not providing enough information, ask follow up question to user until above information is filled.
